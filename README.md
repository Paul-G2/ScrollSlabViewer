# ScrollSlabViewer
A 3D viewer tailored for the scroll volumes of Kaggle's Vesuvius Surface Detection challenge.
</br>

Click on the screenshot below to launch the app in your browser. (Uses WebGL, so a GPU is required.)
</br>

See the [post on Kaggle](https://www.kaggle.com/competitions/vesuvius-challenge-surface-detection/discussion/663144) for more info.
